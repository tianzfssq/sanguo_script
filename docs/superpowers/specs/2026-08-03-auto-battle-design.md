# 自动挂机打仗 — 设计文档

## 概述

微信小游戏（三国 RPG）自动挂机脚本。通过 A/S 键左右移动触发遇敌，利用像素采样检测战斗结束，点击底部退出战斗，循环。

## 方案

B — Python + PyAutoGUI + 底部黑条像素采样

## 主循环

```
while True:
    交替按 A / S（每 0.5s 切换方向）
    每 2s 检测一次画面底部区域
    若底部黑像素占比 > 60%：
        点击底部中央退出战斗
        sleep(1.5) 等地图加载
```

## 可配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SAMPLE_REGION_BOTTOM_RATIO` | 0.15 | 检测区域 = 屏幕底部 15% 高度 |
| `BLACK_THRESHOLD` | 40 | RGB 各通道低于此值视为黑像素 |
| `BLACK_RATIO_THRESHOLD` | 0.6 | 黑像素占比阈值 |
| `DETECT_INTERVAL` | 2.0 | 画面检测间隔（秒） |
| `MOVE_SWITCH_INTERVAL` | 0.5 | A/S 交替间隔（秒） |

## 退出

`Ctrl+C` 优雅退出。

## 风险

- 窗口大小变化需调整检测区域
- 不同分辨率需重新确认黑色阈值
- 首次使用建议手动验证检测区域和阈值是否准确
